# jasonwebsample

Single-page landing site sample — **ELMA — Daily Ritual**.

Static HTML with inline CSS; no build step and no dependencies beyond Google Fonts
(Fraunces + Inter), which load from the CDN.

## Run it

Open `index.html` in a browser, or serve the directory:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
